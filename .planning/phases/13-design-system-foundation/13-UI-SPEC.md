## Spacing Scale

Source: CONTEXT D-08 — Tailwind v4 default 4px-based scale is the canonical scale. **Do NOT
introduce a competing custom `@theme` spacing scale.** This phase standardizes CONSISTENT
APPLICATION of existing utilities, not new tokens. Values below map to existing Tailwind utilities.

| Token | Value | Tailwind utility | Usage |
|-------|-------|------------------|-------|
| xs | 4px | `gap-1` / `p-1` | Icon-to-text gaps, inline padding |
| sm | 8px | `gap-2` / `p-2` | Compact element spacing, EmptyState fine gaps |
| md | 16px | `gap-4` / `p-4` | Default element spacing, card padding |
| lg | 24px | `gap-6` / `p-6` | Card/panel padding, intra-section spacing |
| xl | 32px | `gap-8` / `py-8` | Layout gaps |
| 2xl | 48px | `py-12` | Major sub-section breaks |
| 3xl | 64px | `py-16` | Standard section vertical padding (mobile) |
| 4xl | 96px | `md:py-24` | Standard section vertical padding (desktop) |

**Section rhythm convention (UI-01, the deliverable):**
- Standard public-page section vertical padding = **`py-16 md:py-24`** (64px mobile / 96px desktop).
- Replace the homepage's ad-hoc mix of `py-16` and `py-24` with this single convention so
  spacing reads as intentional. Apply across existing public pages.
- EmptyState vertical padding = `py-16` (matches the API in §EmptyState).

Exceptions:
- Touch targets: interactive controls keep a minimum 44px hit area even when visual padding is
  smaller (icon-only buttons in the portal sidebar / toggle).
- Devanagari line-box: Hindi text may need slightly larger vertical rhythm; do not shrink below
  the scale to compensate.

## Typography

Geist Sans across the board. Two weights only (regular 400, semibold 600). Sizes map to existing
Tailwind utilities — no new font tokens. These are the locked roles for this phase's primitives
(EmptyState) and the standardized public-section headings; richer display scale is Phase 15.

| Role | Size | Weight | Line Height | Tailwind |
|------|------|--------|-------------|----------|
| Body | 16px | 400 | 1.5 | `text-base leading-relaxed` |
| Label / subtext | 14px | 400 | 1.5 | `text-sm` (EmptyState description, muted) |
| Heading | 20px | 600 | 1.2 | `text-xl font-semibold leading-tight` |
| Display | 28px | 600 | 1.2 | `text-3xl font-semibold leading-tight` |

Notes:
- EmptyState title = 16px/600 (`text-base font-semibold`) per §EmptyState API — a compact heading,
  intentionally smaller than the section Heading role since it sits inside a table/panel.
- CountUp stat numbers inherit their parent's display sizing (trust band); CountUp only animates the
  numeric value, it does not set its own type scale.

## Color

The brand identity is preserved across both modes (CONTEXT D-02): blue/green stay as accents,
only surfaces darken, and **dark mode is PORTAL-ONLY** (CONTEXT D-01 — the public site stays light
in all conditions, no toggle anywhere public).

### Light (public site + portal default)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8FAFC` (`--color-bg`) | Page background, section surfaces |
| Secondary (30%) | `#FFFFFF` (`--color-surface`) / `#1E3A5F` (`--color-nav`) | Cards, panels, nav bar |
| Accent (10%) | `#1E40AF` (`--color-primary` blue) | See reserved-for list |
| Accent — success | `#16A34A` (`--color-accent` green) | Trust/success signals only |
| Destructive | shadcn `--destructive` `oklch(0.577 0.245 27.325)` | Destructive actions only |
| Body text | `#0F172A` (`--color-text`) | Primary text |
| Muted text | `#64748B` (`--color-muted`) | Secondary/subtext |
| Border | `#E2E8F0` (`--color-border`) | Dividers |

### Dark (portal only) — brand-token override block to ADD to `app/globals.css`

All accent values below are `[ASSUMED]` from RESEARCH §Brand Token Dark Values and MUST be
WCAG AA verified against the dark surface with a contrast checker before locking (CONTEXT D-02).

| Role | Light | Dark (proposed) | Contrast intent |
|------|-------|-----------------|-----------------|
| Dominant (60%) `--color-bg` | `#F8FAFC` | `#0B1220` | Dark portal background |
| Secondary (30%) `--color-surface` | `#FFFFFF` | `#111827` | Elevated card, lighter than bg |
| `--color-nav` | `#1E3A5F` | `#0F172A` | Deepened nav/sidebar |
| Accent (10%) `--color-primary` blue | `#1E40AF` | `#60A5FA` (blue-400) | ≥4.5:1 on `#0B1220` (verify AA) |
| Accent success `--color-accent` green | `#16A34A` | `#4ADE80` (green-400) | ≥4.5:1 on dark (verify AA) |
| `--color-text` | `#0F172A` | `#F1F5F9` (slate-100) | High-contrast body text |
| `--color-muted` | `#64748B` | `#94A3B8` (slate-400) | ≥4.5:1 muted text (verify AA) |
| `--color-border` | `#E2E8F0` | `#1E293B` (slate-800) | Subtle divider on dark |

**Accent reserved for (10% rule — never "all interactive elements"):**
- Primary blue (`--color-primary`): primary CTA buttons, active nav/sidebar item, key links,
  focus rings, primary stat emphasis in the trust band.
- Success green (`--color-accent`): trust/success signals only (e.g. "PM-JAY empanelled" badge,
  positive status pills). NOT used for generic buttons.
- Destructive: delete/remove confirmations only.

**Implementation flag (highest-uncertainty item — RESEARCH A2 / Open Question 1):** The eight
brand tokens are declared as literal hex inside `@theme inline` (globals.css lines 13-20) AND a
later block (lines 36, 39, 45) re-aliases `--color-primary`/`--color-accent`/`--color-border` to
shadcn `var()` tokens. A Wave-0 spike must confirm a plain `.dark { --color-primary: … }` override
wins; if `@theme` freezes the literals, refactor the eight brand tokens to the `:root` / `.dark`
`var()`-indirection pattern the neutral tokens already use. Do not lock dark hex until verified.

## Motion Contract (UI-03)

framer-motion primitives in `components/motion/`. All restrained/professional (CONTEXT D-06):
short durations, gentle easing, small offsets. **`prefers-reduced-motion` is MANDATORY** — every
primitive calls `useReducedMotion()` (or Tailwind `motion-reduce:` for the CSS path) and renders
the static end-state when motion is disabled.

| Token | Value | Applies to |
|-------|-------|------------|
| Reveal duration | 0.4s | FadeIn |
| CountUp duration | 1.2s | CountUp number animation |
| Hover-lift duration | 0.2s | hover-lift cards |
| Easing | `easeOut` | all primitives |
| Reveal offset (translateY) | 16px | FadeIn initial `y` |
| Hover-lift offset (translateY) | -4px (`-translate-y-1`) | card hover |
| Hover-lift shadow | `shadow-md` on hover | card hover |
| Viewport trigger | `once: true`, amount 0.3 (FadeIn) / 0.5 (CountUp) | scroll reveals |

Primitives:
- `<FadeIn>` — fade + 16px rise on scroll-into-view (`whileInView`). Returns children unwrapped
  when reduced-motion is set.
- hover-lift — **prefer Tailwind-only** for Server-Component cards
  (`transition-transform transition-shadow duration-200 hover:-translate-y-1 hover:shadow-md
  motion-reduce:transition-none motion-reduce:hover:translate-y-0`); provide a framer-motion
  `<HoverLift>` wrapper only for cards already client-side.
- `<CountUp value suffix>` — 0→target on scroll-into-view; renders final value immediately when
  reduced-motion. Non-numeric stats (e.g. `24x7`) stay static literals, not animated.

Proof of adoption (D-07): wrap the homepage trust-signals band in one `<FadeIn>`; render
`90`→`<CountUp value={90}/>`, `25+`→`<CountUp value={25} suffix="+"/>`, `8`→`<CountUp value={8}/>`,
`24x7` static. Keep `page.tsx` an async RSC; motion is nested client islands only.

## EmptyState Anatomy (UI-04)

Presentational, RSC-compatible component at `components/ui/empty-state.tsx` (matches components.json
`ui` alias). Lucide icon + heading + subtext + optional action slot. No custom SVG illustrations
(CONTEXT D-09). Uses token classes so it renders correctly in portal dark mode automatically.

| Element | Spec |
|---------|------|
| Container | `flex flex-col items-center gap-3 py-16 text-center` |
| Icon | lucide `LucideIcon` prop, `h-10 w-10 text-muted-foreground`, `aria-hidden` |
| Title | `text-base font-semibold text-foreground` (required string) |
| Description | `text-sm text-muted-foreground max-w-sm` (optional) |
| Action | optional `ReactNode` slot (shadcn `<Button>`) |

Props: `{ icon: LucideIcon; title: string; description?: string; action?: ReactNode; className?: string }`

Adoption proof (D-09): replace the plain-text "No items yet" blocks in
`DepartmentsClient.tsx` (lines ~203-211), `DoctorsClient.tsx`, `FacilitiesClient.tsx`. Migrate at
least one; ideally all three (near-identical, low marginal cost).

## Copywriting Contract

Hospital tone: calm, credible, plain. The portal is English-only; the public site is bilingual but
this phase touches only portal empty states (English) and the existing public trust band.

| Element | Copy |
|---------|------|
| Primary CTA (EmptyState action) | "Add Department" / "Add Doctor" / "Add Facility" (verb + entity) |
| Empty state heading | "No departments yet" / "No doctors yet" / "No facilities yet" |
| Empty state body | "Add your first {entity} to display it on the public site." |
| Error state | "Couldn't load {entity}. Refresh the page or try again in a moment." |
| Destructive confirmation | Out of scope this phase — no destructive flows introduced. Existing portal delete confirmations unchanged. |

Dark-mode toggle (portal sidebar, D-03): label/`aria-label` = "Toggle theme" (or "Dark mode").
No public-facing copy added — the toggle never appears on the public site.
