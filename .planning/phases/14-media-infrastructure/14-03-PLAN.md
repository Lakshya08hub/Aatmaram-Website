    Body steps in order:
    1. `await requireCmsRole()`
    2. Extract file: `const file = formData.get('image') as File | null` — return `{ error: 'No file selected' }` if null or size 0
    3. Validate MIME: allowed = `['image/jpeg', 'image/png', 'image/webp']` — return `{ error: 'Only JPG, PNG, or WebP files are allowed.' }` if not in list
    4. Validate size: `if (file.size > 5 * 1024 * 1024) return { error: 'File exceeds 5 MB. Choose a smaller image.' }`
    5. Build path: `const ext = file.type === 'image/jpeg' ? 'jpg' : file.type.split('/')[1]` then `const path = \`${folder}/${entityId}-${Date.now()}.${ext}\``
    6. Convert: `const bytes = await file.arrayBuffer()`
    7. Admin client: `const admin = createAdminClient()`
    8. Upload: `admin.storage.from('media').upload(path, bytes, { contentType: file.type, upsert: true })` — if uploadErr, throw new Error(uploadErr.message)
    9. Get URL: `const { data: { publicUrl } } = admin.storage.from('media').getPublicUrl(path)`
    10. DB write: `admin.from(table).update({ [column]: publicUrl }).eq('id', entityId)` — if dbErr, throw new Error(dbErr.message)
    11. Revalidate (call the correct set by folder):
        - doctors: revalidatePath('/en/doctors'), revalidatePath('/hi/doctors'), revalidatePath('/portal/content/doctors')
        - departments: revalidatePath('/en/departments'), revalidatePath('/hi/departments'), revalidatePath('/portal/content/departments')
        - facilities: revalidatePath('/en/facilities'), revalidatePath('/hi/facilities'), revalidatePath('/portal/content/facilities')
        - site: revalidatePath('/en'), revalidatePath('/hi')
    12. Return `{ url: publicUrl }`

    Export 2 — deleteImageAction:
    Signature: `async function deleteImageAction(entityId: string, table: 'doctors' | 'departments' | 'facilities' | 'hospital_info', column: 'photo_url' | 'image_url' | 'hero_image_url', storedUrl: string): Promise<{ error?: string }>`

    2. Extract path from URL: `const urlObj = new URL(storedUrl); const storagePath = urlObj.pathname.split('/object/public/media/')[1]` — if no match, skip Storage delete (it may be a legacy external URL)

    4. DB write: `admin.from(table).update({ [column]: null }).eq('id', entityId)` — if dbErr, throw
    5. Same revalidatePath logic as upload (by table/folder)
    6. Return `{}`
