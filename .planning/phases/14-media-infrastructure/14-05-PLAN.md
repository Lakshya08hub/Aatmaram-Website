    Props interface: `{ heroImageUrl: string | null; hospitalInfoId: string }`

    State: `const [uploading, setUploading] = useState(false)`

    Layout structure:
    - Outer div: `className="space-y-6"`
    - Heading: `<h1 className="text-xl font-semibold">Site Images</h1>`
    - Card for hero (use div with border/rounded/p-4 or shadcn Card if already installed):
      - Card heading: `<p className="font-medium mb-3">Homepage Hero Background</p>`
      - If heroImageUrl is set: show `<div className="relative w-full aspect-video rounded overflow-hidden mb-3"><Image src={heroImageUrl} alt="" fill sizes="100vw" className="object-cover" priority /></div>`
      - If heroImageUrl is null/empty: show `<EmptyState icon={ImagePlus} title="No hero image set" description="Upload an image to display as the homepage background. Without one, the default navy background is shown." />`
      - Below preview/empty-state: file input and optional remove button

    File input onChange handler:
    - Get file from e.target.files[0]; return if none
    - Client-side validation: if file.size > 5 * 1024 * 1024, toast.error('File exceeds 5 MB. Choose a smaller image.') and return
    - if !['image/jpeg','image/png','image/webp'].includes(file.type), toast.error('Only JPG, PNG, or WebP files are allowed.') and return
    - setUploading(true)
    - Build FormData: fd.append('image', file)
    - Call `uploadImageAction(fd, 'site', hospitalInfoId, 'hospital_info', 'hero_image_url')`
    - On result.url: toast.success('Hero image uploaded'), router.refresh()
    - On result.error: toast.error(result.error ?? 'Upload failed')
    - finally: setUploading(false)

    File input element:
    - Same className as CRUD forms (text-sm, file: classes)
    - accept="image/jpeg,image/png,image/webp"
    - disabled={uploading}
    - Label text: if heroImageUrl then "Replace Image" else "Upload Image" (shown as a label above or as a button-styled label)
    - Hint text below: `<p className="text-xs text-muted-foreground">JPG, PNG or WebP — max 5 MB</p>`

    Uploading indicator: Loader2 spinner + "Uploading…" text shown when uploading is true.

    Remove button (shown only when heroImageUrl is set):
    - `<Button variant="destructive" size="sm" onClick={handleRemove}>Remove</Button>`
    - handleRemove: setUploading(true), call deleteImageAction(hospitalInfoId, 'hospital_info', 'hero_image_url', heroImageUrl), on success toast.success('Hero image removed') + router.refresh(), finally setUploading(false)
    - Inline confirmation before remove: show an inline "Are you sure?" state (a local boolean state `confirmRemove`) — if confirmRemove is false, show "Remove" button that sets confirmRemove=true; if confirmRemove is true, show "The image will be deleted. This cannot be undone." text with "Remove" (destructive) + "Cancel" (ghost) buttons side by side, Cancel sets confirmRemove=false.
