<objective>
Update the three portal CRUD Client Components — DepartmentsClient, DoctorsClient, FacilitiesClient — to replace the plain image URL text input with a file upload control that calls uploadImageAction on file selection.

Purpose: Per D-06, entity image uploads live inline on their existing forms. The upload-on-select pattern (not upload-on-submit) stores the image immediately in Storage and puts the public URL into a hidden form field; the existing create/update action receives it as a plain string — no form submission re-architecture needed.

Output: Three modified Client Components with file inputs that upload on selection, show previews, and handle the create-form edge case.
</objective>
