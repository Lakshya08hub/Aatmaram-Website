    Create `components/portal/InlineEditCell.tsx` as a Client Component (`'use client'`).

    Implement exactly the pattern described in RESEARCH.md lines 254-316 with these specifics:

    Props interface:
    - `value: string` — current value to display and edit
    - `onSave: (newValue: string) => Promise<{ error?: string }>` — async save callback; returns error string on failure
    - `className?: string` — optional class overrides

    State:
    - `editing: boolean` — whether the cell is in edit mode
    - `localValue: string` — local copy of value during editing
    - `ringState: 'idle' | 'saving' | 'success' | 'error'`

    View mode (not editing):
    - Renders a `<span>` with `cursor-text hover:underline decoration-dotted` plus a small pencil icon (Pencil from lucide-react, h-3 w-3, `text-muted-foreground ml-1 inline opacity-0 group-hover:opacity-100`)
    - Wrap the span in a `group` div so pencil shows on hover
    - `onClick` sets `editing=true`

    Edit mode:
    - Renders `<Input ref={inputRef}` with `autoFocus`, `value={localValue}`, `onChange`, `onBlur={handleSave}`, `onKeyDown`
    - `onKeyDown`: Enter → `e.preventDefault(); handleSave()`, Escape → `setLocalValue(value); setEditing(false); setRingState('idle')`
    - Input className: `h-7 px-1 py-0` plus ring classes:
      - idle or saving: `ring-2 ring-blue-500`
      - success: `ring-2 ring-green-500`
      - error: `ring-2 ring-red-500`
      - saving: add `opacity-70`

    `handleSave` async function:
    - If `localValue === value`: `setEditing(false); return` (no-op, no toast)
    - `setRingState('saving')`
    - `const result = await onSave(localValue)`
    - On error: `setRingState('error'); toast.error('Could not save — please try again.')`
    - On success: `setRingState('success'); setTimeout(() => setRingState('idle'), 600); setEditing(false)`
    - Cleanup: clear the timeout ref on unmount using `useEffect` return

    Imports:
    - `'use client'`
    - `useState, useRef, useEffect` from `react`
    - `Input` from `@/components/ui/input`
    - `cn` from `@/lib/utils`
    - `toast` from `sonner`
    - `Pencil` from `lucide-react`

    Do NOT add `router.refresh()` inside InlineEditCell — that belongs in the parent caller's `onSave` callback, since the parent knows whether to refresh.

| T-16-07 | Elevation of Privilege | InlineEditCell onSave callbacks | mitigate | Each Server Action called from onSave already calls `requireCmsRole()` or role equivalent — no bypass possible from client |
| T-16-08 | Tampering | InlineEditCell value → Server Action | mitigate | Use controlled `<Input>` (not contentEditable) — React escapes all values; Server Actions whitelist explicit fields (no spread) |
