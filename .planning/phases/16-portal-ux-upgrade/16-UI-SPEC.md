## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline cell padding |
| sm | 8px | Card inner padding, compact row padding |
| md | 16px | Default card padding, sidebar item padding |
| lg | 24px | Section padding, kanban column padding |
| xl | 32px | Dashboard grid gap |
| 2xl | 48px | Sidebar collapsed width (icon-only rail) |
| 3xl | 64px | Full sidebar width breakpoint gutter |

## Color

All values use shadcn CSS variable tokens (semantic layer). Raw oklch values from `app/globals.css` shown as reference.

| Role | Token | Light Value | Dark Value | Usage |
|------|-------|-------------|------------|-------|
| Dominant (60%) | `bg-background` | oklch(1 0 0) white | oklch(0.145 0 0) near-black | Page background, table rows |
| Secondary (30%) | `bg-card` | oklch(1 0 0) white | oklch(0.205 0 0) dark surface | Cards, sidebar, kanban column bg, metric cards |
| Accent (10%) | `--color-accent` `#16A34A` | #16A34A green | same (via var indirection) | See reserved list below |
| Primary brand | `--color-primary` `#1E40AF` | #1E40AF blue | same | Sidebar active item, primary buttons, inline edit ring |
| Destructive | `bg-destructive` | shadcn red token | shadcn red token | Delete actions, cancel column header badge only |
| Muted | `text-muted-foreground` | oklch(0.556 0 0) | oklch(0.708 0 0) | Placeholder text, stat card subtitles, payroll placeholder |

Accent (#16A34A green) reserved for:
- "Confirmed" status badge on kanban cards
- Inline edit success ring flash (`ring-green-500` for ~600ms after save)
- Active/featured toggle ON state indicator dot

Primary (#1E40AF blue) reserved for:
- Inline edit active cell ring (`ring-2 ring-blue-500`)
- Sidebar active nav item background/indicator
- Primary action buttons (advance kanban status, save confirmation toasts)
- Contacted status badge on kanban cards

Kanban column header badges use established portal StatusBadge colors:
- Pending: amber (`bg-amber-100 text-amber-800 dark:bg-amber-900 dark:text-amber-200`)
- Contacted: blue (`bg-blue-100 text-blue-800 dark:bg-blue-900 dark:text-blue-200`)
- Confirmed: green (`bg-green-100 text-green-800 dark:bg-green-900 dark:text-green-200`)
- Cancelled/Completed: muted red (`bg-red-100 text-red-800 dark:bg-red-900 dark:text-red-200`)

Dark mode implementation rule: Use shadcn semantic tokens (`bg-background`, `text-foreground`, `bg-card`, `border-border`, `text-muted-foreground`) as the first choice. Only add explicit `dark:` Tailwind classes when a hardcoded color has no semantic token equivalent (e.g., the kanban badge colors above).

## Interaction Contracts

### Inline Editing

| State | Visual |
|-------|--------|
| Default (view) | Plain text in table cell, cursor: text on hover |
| Hover | Subtle underline or pencil icon (12px, muted) to signal editability |
| Active (edit) | Input or contentEditable with `ring-2 ring-blue-500 rounded-sm` |
| Saving | Ring stays blue, opacity-70 on input |
| Success | Ring flashes to `ring-green-500` for 600ms, then disappears |
| Error | Ring turns `ring-red-500`, toast error appears via Sonner |

Auto-save triggers on: blur, Enter keypress. Cancel on Escape (reverts to original value).

### Kanban Advance Button

- Each kanban card shows a single forward-advance button in the bottom-right corner (chevron-right icon + label, e.g., "Mark Contacted").
- Button is 44px min-height, `variant="outline"` size="sm".
- Cancelled and Completed cards show no advance button.
- Status transitions: Pending → Contacted → Confirmed → Completed. Separate "Cancel" action available on Pending and Contacted cards only (destructive, requires confirm dialog).

### Kanban Scroll Hint Animation (mobile/tablet)

```css
@keyframes scroll-hint {
  0%   { transform: translateX(0); }
  30%  { transform: translateX(-60px); }
  60%  { transform: translateX(-60px); }
  100% { transform: translateX(0); }
}
```

- Plays once on mount with `animation-fill-mode: both; animation-duration: 1.2s`.
- Applied to the scrollable kanban container.
- `@media (prefers-reduced-motion: reduce)` must disable this animation entirely.

### Sidebar Collapse (tablet)

- On `md` screens (768px–1023px): sidebar renders at `w-12` (48px) showing only Lucide icons.
- Each icon-only nav item shows a Tooltip (shadcn Tooltip) with the label on hover.
- On `lg` screens (1024px+): sidebar renders at `w-64` with icon + label text.
- Toggle button is a chevron-left/right icon at the bottom of the sidebar. Clicking it overrides the responsive default for that session (persisted in component state only, no localStorage).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Dashboard payroll placeholder | `₹—` (stat value) + `"Payroll tracker coming in a later phase"` (muted subtext) |
| Kanban empty column (Pending) | `"No pending appointments"` heading + `"New appointment requests from patients will appear here."` body |
| Kanban empty column (Contacted) | `"No appointments in progress"` + `"Appointments you've contacted will appear here."` |
| Kanban empty column (Confirmed) | `"No confirmed appointments"` + `"Confirmed appointments will appear here."` |
| Kanban empty column (Cancelled/Completed) | `"Nothing here yet"` + `"Cancelled or completed appointments will appear here."` |
| Inline edit error toast | `"Could not save — please try again."` (Sonner error toast, 4s) |
| Inline edit success (no toast, visual ring only) | Ring flash only — no toast for routine inline saves to reduce noise |
| Kanban advance error toast | `"Status update failed — please try again."` |
| Kanban cancel confirm dialog | Title: `"Cancel this appointment?"` Body: `"This will move the appointment to Cancelled. The patient will not be notified automatically."` Confirm: `"Yes, cancel"` (destructive) Dismiss: `"Keep appointment"` |
| Staff table empty state | `"No staff members yet"` + `"Add staff members to give them portal access."` |
| Patients table empty state | `"No patient records yet"` + `"Create the first patient record using the button above."` |
| Content table empty state (generic) | `"Nothing here yet"` + `"Add the first entry using the button above."` |
| Dashboard date range label | `"Last 30 days"` (static, no picker) |
| Sidebar tooltip labels | Exact nav labels: Dashboard, Appointments, Patients, Staff, Content, Settings |

Primary CTAs per section:
- Dashboard: no primary CTA (read-only view)
- Kanban advance: `"Mark [Next Status]"` (e.g., "Mark Contacted", "Mark Confirmed", "Mark Completed")
- Inline edit: no explicit CTA — interaction is click-initiated

|--------|------------|-------------|-------------|
